## FixMyTown

### Municipal Issue Reporting System

FixMyTown allows citizens to report municipal problems and follow them throughout the entire resolution process.

A report can be tracked from:

`Submitted → Assigned → Attended → Resolved`

The system includes:

- Citizen dashboard
- Administrator dashboard
- Worker management
- Issue assignment
- Location-based reports
- Report filtering and search
- Progress tracking
- Excel report exports
- Authentication and authorization
- Email-based password recovery

### Technology

`ASP.NET Core` `React` `SQL` `REST API` `ClosedXML`
